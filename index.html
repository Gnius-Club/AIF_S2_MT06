🎯 Objetivo de Aprendizaje

Los estudiantes podrán: comprender el pensamiento lógico y la arquitectura conceptual basada en estados, para usar Delightex implementando variables y lógica condicional simple al crear mecánicas de juego.

🤖 Prompt de Referencia para XOLO (Solo para Maestro)

⚠️ NOTA: XOLO ya conoce el tema de esta misión. Este prompt es SOLO de referencia en caso de emergencia técnica: 
Explícame qué es una variable y por qué se usa para "guardar información" en un mundo interactivo. Luego, enséñame cómo funciona una condición simple (if): "si ocurre esto, entonces sucede aquello". Guíame a comprender cómo estas reglas se usan para crear mecánicas de juego como acertijos. Finalmente, conecta esto con una idea preparatoria de arquitectura de software: cómo pensar en términos de "estados" y "condiciones" ayuda a diseñar experiencias digitales complejas.

📊 Diapositiva 3: Brain Spark

1. 💬 Pide a XOLO que te ayude a crear:

"Ayúdame a idear un acertijo simple en Delightex que use una condición (if). Quiero una vibe (ej. "búsqueda de llave", "código secreto", "objeto oculto"). Guíame para planear el estado inicial (portal cerrado), el evento clave (clic en llave) y la condición (si la llave fue tomada, entonces se activa el portal). Después indícame cómo estructurar esta mecánica paso a paso para que el acertijo sea claro y divertido."

2. 🔬 Experimenta y descubre con tu acertijo:

  • ¿Funciona el acertijo como esperabas al interactuar con el objeto?
  • ¿Qué pasa si intentas activar el portal sin haber recogido la llave primero?
  • ¿Funciona igual si cambias el orden de los eventos en tu lógica?
  • ¿Cómo ayuda el pensamiento lógico a que el jugador no se confunda en tu acertijo?
  • Si el sistema cambia de 'cerrado' a 'abierto', ¿cómo se refleja esto en tu arquitectura de estados?

¡Es hora de crear! Vamos a usar lo aprendido para diseñar un acertijo real en Delightex. Primero, platiquen con XOLO para idear un VIBE, como una búsqueda de tesoro o un código secreto. Él les dará un plan de diseño para que sepan exactamente qué condiciones configurar. Por ejemplo, podrían hacer que un portal solo se abra si el jugador encuentra una gema oculta. Una vez que tengan la idea, configuren la lógica en Delightex, prueben en modo juego y vean si el acertijo es divertido. Si algo no funciona o tienen dudas, pregúntenle a XOLO, él los ayudará a mejorar la estructura de su lógica.
